One single-line joke about a meeting that should have been an email (121 characters):

> We spent 45 minutes in a meeting reading the email aloud, then emailed everyone a summary of the meeting about the email.

The joke is recognition with a recursive twist: the meeting exists only to read the email aloud, and its only output is an email summarizing the meeting about the email. The turn lands on the very last words.

## Run it
